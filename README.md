# Quotely

A quote browsing app built with SwiftUI that fetches quotes from a REST API.

## Overview

Quotely was created as part of my iOS development training.

The application retrieves quotes from an external API and displays them in a simple and clean interface. It also demonstrates working with remote data and asynchronous network requests.

## Technologies

- Swift
- SwiftUI
- REST API
- URLSession
- Xcode

## Features

- Fetch quotes from an external API
- Display quote content and author information
- Handle asynchronous network requests
- Decode JSON responses
- Update the UI with fetched data

## What I Practiced

- Working with REST APIs
- Making network requests with `URLSession`
- Decoding JSON with `Decodable`
- Handling asynchronous operations
- Managing loading and error states
- Building SwiftUI interfaces for dynamic data

## Security

API credentials are not stored in the repository.
